# ProfileForge Launch Timeline

A full, coordinated calendar to launch ProfileForge to the world.

## T-7 Days: Pre-seeding
- **Action**: Share initial prototype with close developer contacts and early beta testers.
- **Twitter**: Post a "sneak peek" GIF of the CLI rendering a profile in <15ms. ("Working on something fast... ⚡️")
- **Reddit**: Find 3-5 relevant questions on r/github about profile customizations and drop helpful comments mentioning a tool you're building to solve it.

## T-3 Days: Final Polish
- **Content**: Finalize all copy for HackerNews, Product Hunt, and Reddit.
- **Assets**: Record final demo GIF of ProfileForge Studio in action.
- **Links**: Verify all GitHub links, PyPI links, and documentation URLs.
- **Drafts**: Prepare the Product Hunt draft page (don't submit yet).

## T-1 Days: Warm-up
- **Twitter**: Schedule the 12-tweet launch thread for 8:00 AM PT tomorrow.
- **HackerNews**: Pre-write the Show HN post and the mandatory first comment explaining the tech stack.
- **Product Hunt**: Warm up the Maker comment on the draft page.

- **08:05 AM**: Submit "Show HN: ProfileForge – Declarative GitHub Profile & SVG Widget Engine" on HackerNews. Add first comment immediately.
- **08:15 AM**: Post Twitter launch thread.
- **08:20 AM**: Publish professional post on LinkedIn.
- **08:30 AM**: Post on r/github (casual tone) and r/Python (technical tone).
- **09:00 AM - 08:00 PM**: Active monitoring. Respond to every HN, PH, and Reddit comment within 10-15 minutes. Retweet/quote positive feedback.

## T+1 Days: Follow-through
