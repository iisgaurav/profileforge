# Minimalist Developer Starter Template

An ultra-clean, monochromatic ProfileForge template built for software engineers who value understated elegance and concise presentation.

## Included Widgets
- **Hero (`hero`)**: Crisp typographic header with name, role, subtle status chip, and core philosophy.
- **About (`about`)**: Concise developer statement, values, and collaboration status.
- **Featured Repositories (`repositories`)**: Pinned repositories with minimal star/fork indicators and language badges.

## Theme
- Default: `minimal` (monochrome black & white / slate gray aesthetics).

## Quick Start
```bash
# Build SVG profile widgets
profileforge build

# Validate configuration
profileforge validate
```
