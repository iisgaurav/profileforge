# Backend Engineer Starter Template

A production-ready ProfileForge template designed for backend developers, distributed systems architects, and platform engineers.

## Included Widgets
- **Hero (`hero`)**: Identity card with title, availability status badge, tagline, and location.
- **Technical Skills (`skills`)**: Categorized badges showcasing backend languages (Go, Python, Rust), databases (PostgreSQL, Redis), cloud & containerization (Docker, Kubernetes, AWS), and distributed messaging (Kafka, gRPC).
- **Featured Repositories (`repositories`)**: Pinned open-source and backend service repositories with star counts, forks, and language badges.
- **GitHub Stats (`github_stats`)**: Live developer metrics, total stars, pull requests, commits, and aggregate developer score.
- **Work Experience (`experience`)**: Timeline of engineering leadership, scalable system milestones, and architectural impact.

## Theme
- Default: `github-dark` (also compatible with `vercel`, `nord`, or `modern`).

## Quick Start
```bash
# Build SVG profile widgets
profileforge build

# Validate configuration
profileforge validate
```
