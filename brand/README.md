# Brand system overview
- Project name: ProfileForge, Tagline: "Forge your GitHub profile."
- Logo usage rules: minimum size (120px wide), clear space (equal to cap-height of P on all sides)
- Color-on-color rules: white text on primary, never primary on white
- Don'ts: don't distort, rotate, recolor; don't use on busy backgrounds; don't change fonts
- Available assets table: logo.svg, icon.svg, banner.svg, favicon.svg
