# Typography system
- Primary: Inter (Google Fonts) for all UI and documentation
- Monospace: JetBrains Mono for code blocks, CLI output, widget IDs
- Type scale table: 12px caption, 14px body-sm, 16px body, 20px lead/widget titles, 24px h3, 32px h2, 48px h1
- Weight guide: 400 Regular, 500 Medium, 600 SemiBold, 700 Bold
- Line height: 1.4 body, 1.2 headings, 1.6 docs
