# Design Tokens

ProfileForge uses a token-based architecture to ensure visual consistency.

## Color Tokens
- `primary`: Main brand color.
- `secondary`: Supporting brand color.
- `background`: Card or canvas background.
- `surface`: Elevated surface background.
- `border`: Component borders.
- `text`: Primary text.
- `muted`: Secondary text.
- `success`, `warning`, `info`, `accent`: Semantic colors.

## Typography Tokens
- `font_family`: Base font stack.
- `heading`: Font size for titles.
- `body`: Standard text size.
- `small`: Small text size.

## Spacing Tokens
- `xs` (4px)
- `sm` (8px)
- `md` (16px)
- `lg` (24px)
- `xl` (32px)

## Radius Tokens
- `card`: Card border radius.
- `progress`: Progress bar border radius.
- `badge`: Badge border radius.

## Shadow & Motion Tokens
Tokens for configuring elevation and animation durations across the widget ecosystem.
