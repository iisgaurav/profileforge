# ProfileForge Design Language

ProfileForge aims to create beautiful, developer-centric widgets that look natively integrated into GitHub while offering a premium aesthetic.

## Core Principles

1. **Information Density**: Maximize data visibility without overwhelming the user.
2. **Consistency**: Use unified design tokens across all components.
3. **Accessibility**: Maintain high contrast ratios for readability.
4. **Delight**: Use subtle gradients, shadows, and animations to create a premium feel.

## Visual Primitives

- **Typography**: Clean, readable sans-serif fonts for data, monospaced fonts for code and metrics.
- **Spacing**: A strict 4px/8px grid system.
- **Radius**: Consistent border radii for cards (8px) and badges (4px).

All widgets must adhere to these principles to be accepted into the core registry.
