# ProfileForge Version Roadmap

This document outlines the strategic versioning roadmap for the ProfileForge project.

### v0.1.x (Current Phase)
- Stabilization
- Documentation
- Bug fixes
- Better examples

### v0.2
- More built-in widgets (e.g., Projects, TechRadar)
- Theme inheritance and improvements
- Better diagnostic tools

### v0.3
- Plugin API stabilization
- Third-party widget support (community marketplace)
- Additional Data Sources (e.g., GitHub GraphQL, WakaTime)

### v1.0
- Stable public API
- Complete documentation
- Migration guide
- Long-term compatibility guarantees
