# Engineering Roadmap

This document outlines the public-facing timeline for ProfileForge.

| Status | Version | Target | Description |
|--------|---------|--------|-------------|
| ✅ Done | **RC1 (Current)** | Now | Feature-complete Core Engine. 15 core widgets, 14 themes, 9 persona templates. Studio v1 released. CI/CD GitHub Actions working. Strict performance budgets implemented. |
| 🚧 In Progress | **v1.0.0** | Q3 2026 | **The Official Release**. Community Registry beta launch. New install CLI command (planned). Python 3.13 support. Gallery and documentation polish. |
| 📅 Planned | **v1.1.0** | Q4 2026 | **Studio v2**. Drag-and-drop visual layout builder. Visual theme customizer UI. Live instant SVG preview. Export to YAML directly from the browser. |
| 📅 Planned | **v2.0.0** | 2027 | **Marketplace & Cloud**. Community marketplace web app. OAuth GitHub login for hosted, one-click deployments. Team and organization profiles. Enhanced analytics. |

## Legend
- ✅ Done
- 🚧 In Progress
- 📅 Planned

*Note: Dates and features are subject to change based on community feedback and contributor bandwidth.*
