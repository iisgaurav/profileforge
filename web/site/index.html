🚀 30-Second Quickstart

Up and running in seconds

Pick the path that fits your workflow — CLI scaffold or zero-install Studio.

terminal
1# Install ProfileForge
$ pip install profileforge
2# Scaffold a persona template
$ profileforge scaffold backend
✔ Created config/hero.yaml
✔ Created config/skills.yaml
✔ Created profileforge.yaml
3# Build your profile SVGs
$ profileforge build
✔ 5 widgets built in 23ms ⚡
💡 Available templates: backend, frontend, ai-engineer, student, minimal and 4 more.
