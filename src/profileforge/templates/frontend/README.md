# Frontend Engineer Starter Template

A vibrant, modern ProfileForge template designed for frontend architects, UI engineers, and design technologists.

## Included Widgets
- **Hero (`hero`)**: Design-first developer identity header showcasing title, location, tagline, and creative focus.
- **Technical Skills (`skills`)**: Categorized badges featuring modern UI frameworks (React, Next.js), typed tooling (TypeScript), styling paradigms (Tailwind CSS, CSS Modules), and testing (Playwright, Jest).
- **Featured Repositories (`repositories`)**: Pinned frontend components, design systems, and web applications with star counts and language indicators.
- **GitHub Stats (`github_stats`)**: Clean analytical summary of repositories, commits, pull requests, and developer score.
- **Now (`now`)**: Active learning goals, ongoing UI component builds, design reads, and engineering focus.

## Theme
- Default: `modern` (also compatible with `apple`, `vercel`, or `catppuccin-mocha`).

## Quick Start
```bash
# Build SVG profile widgets
profileforge build

# Validate configuration
profileforge validate
```
