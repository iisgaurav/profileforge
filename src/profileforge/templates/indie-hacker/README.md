# Indie Hacker & Solopreneur Profile Starter

This template is tailored for solo founders, bootstrappers, and indie hackers building micro-SaaS and digital products in public.

## Widgets Included

1. **Hero:** Name, solo founder role, status badge, and tagline.
2. **Contribution Streak:** Contribution streaks and daily shipping habits.
3. **Featured Repositories:** Live stars and forks for your open-source tools and products.
4. **Focus & Revenue:** Active products, MRR milestones, and monthly shipping roadmap.
5. **Achievements:** Solo founder awards and shipping milestones.
6. **Social Links:** Links to Twitter/X, Product Hunt, YouTube, and Substack.

## Quick Start

```bash
# Build profile widgets
profileforge build

# Run local performance benchmark
profileforge benchmark
```
