# Student & Early Career Developer Starter Template

An energetic, learning-focused ProfileForge template created for computer science students, bootcamp graduates, and early-career developers.

## Included Widgets
- **Hero (`hero`)**: Friendly identity header displaying university/education focus, internship seeking status, and passions.
- **Technical Skills (`skills`)**: Organized skill tags spanning foundational CS languages (Python, Java, C++), web development, and dev tooling.
- **Learning Roadmap (`roadmap`)**: Visual progress indicators for core milestones (Data Structures & Algorithms, System Design, Open Source, Cloud).
- **Featured Repositories (`repositories`)**: Pinned class projects, hackathon winners, and open-source contributions.
- **Social Links (`social`)**: Direct links to GitHub, LinkedIn, Twitter, Discord, and portfolio.

## Theme
- Default: `catppuccin-mocha` (also compatible with `nord`, `dracula`, or `github-dark`).

## Quick Start
```bash
# Build SVG profile widgets
profileforge build

# Validate configuration
profileforge validate
```
