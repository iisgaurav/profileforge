# AI & Machine Learning Engineer Starter Template

A specialized, cutting-edge ProfileForge template designed for AI/ML engineers, foundation model researchers, and generative AI builders.

## Included Widgets
- **Hero (`hero`)**: High-impact developer banner displaying role, active research focus, model training status, and location.
- **Technical Skills (`skills`)**: Grouped badges spanning deep learning frameworks (PyTorch, JAX), LLM orchestrators (LangChain, LlamaIndex), hardware acceleration (CUDA, Triton), and inference engines (vLLM, ONNX, TensorRT).
- **Featured Repositories (`repositories`)**: Pinned model repositories, agent frameworks, and training pipelines with star counts and language indicators.
- **Now (`now`)**: Active fine-tuning experiments, paper readings, agentic workflows under development, and research focus.
- **GitHub Stats (`github_stats`)**: Live engineering statistics, repository impact, pull requests, and developer score.

## Theme
- Default: `dracula` (also compatible with `modern`, `github-dark`, or `nord`).

## Quick Start
```bash
# Build SVG profile widgets
profileforge build

# Validate configuration
profileforge validate
```
