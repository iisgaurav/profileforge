# Open Source Maintainer Starter Template

A high-impact, GitHub-native ProfileForge template crafted for open-source maintainers, library authors, and developer advocates.

## Included Widgets
- **Hero (`hero`)**: Community-facing header highlighting active maintenance status, mission statement, and global presence.
- **Featured Repositories (`repositories`)**: Pinned open-source libraries, CLI tools, and packages with star counts, forks, and language tags.
- **GitHub Stats (`github_stats`)**: Live summary of total stars, pull requests merged, contributions, and developer score.
- **Language Distribution (`github_languages`)**: Visual breakdown of top languages used across public repositories.
- **Social & Community (`social`)**: Links to GitHub sponsors, Discord community, Mastodon, Twitter, and developer blog.

## Theme
- Default: `github-dark` (the quintessential dark GitHub ecosystem theme).

## Quick Start
```bash
# Build SVG profile widgets
profileforge build

# Validate configuration
profileforge validate
```
